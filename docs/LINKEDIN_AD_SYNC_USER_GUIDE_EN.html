1. Overview & architecture

The LinkedIn Ad Sync Lightning component imports company-level ad metrics from LinkedIn (Professional demographics / Company Name Segment), stores them in Salesforce, and pushes updates to HubSpot Companies via an Apex batch job. 

flowchart TB
    subgraph LinkedIn
        CM[Campaign Manager]
        API[LinkedIn REST API]
        CM -->|CSV export| CSV[CSV file]
        CM --> API
    end
    subgraph Salesforce
        LWC[LinkedIn Ad Sync LWC]
        MET[(LinkedIn Ad Metric)]
        SET[Integration Settings]
        SCH[LinkedInAdSyncScheduler]
        BAT[LinkedInAdMetricHubSpotBatch]
        LWC --> MET
        SET --> LWC
        SCH -->|daily fetch| API
        SCH --> MET
        SCH --> BAT
        LWC -->|manual fetch| API
        LWC -->|Push to HubSpot| BAT
    end
    subgraph HubSpot
        CO[Companies - match by name]
    end
    CSV --> LWC
    API --> LWC
    BAT --> CO
Design principle: Salesforce is the staging layer. HubSpot is updated only after data is stored locally. Companies are matched by exact name — HubSpot does not auto-create records.

3. Access & prerequisites

Salesforce

  • Tab LinkedIn Ad Sync (or app containing the component)
  • Read/write on LinkedIn_Ad_Metric__c and org Custom Settings

LinkedIn

  • Marketing / Advertising API access with ad analytics reporting scopes
  • Access token (long tokens use secure store via Use LinkedIn Named Credential)
  • Optional: Refresh token + Client Id/Secret for automatic token renewal
  • Ad Account URN, e.g. urn:li:sponsoredAccount:506515554

HubSpot

  • Private App token with Companies read/write
  • Custom company properties for LinkedIn metrics (see section 9)

4. Initial setup (first time)

flowchart LR
    A[API Settings] --> B[Test LinkedIn]
    A --> C[Test HubSpot]
    B --> D[Sync tab defaults]
    D --> E[Fetch or CSV]
    E --> F[Push to HubSpot]
    F --> G[Optional: Schedule Daily Job]
  1. Open LinkedIn Ad Sync → API Settings
  2. Enter LinkedIn Access Token, Ad Account URN, API version (default 202607)
  3. Enter HubSpot Access Token (or enable Named Credential)
  4. Click Save Settings
  5. Click Test LinkedIn and Test HubSpot — both should return SUCCESS
  6. Go to Sync → enter Campaign Name + Campaign Id → Save Sync Defaults
  7. Run first import (CSV or Fetch) → Push to HubSpot (Batch)

7. HubSpot batch sync

The batch job LinkedInAdMetricHubSpotBatch syncs staged Salesforce records to HubSpot. It processes rows where HubSpot Sync Status is Pending or Failed. 

flowchart LR
    A[Pending/Failed rows] --> B[Match HubSpot by name]
    B -->|Found| C[Update metrics]
    B -->|Not found| D[Skipped]
    C -->|OK| E[Synced]
    C -->|Error| F[Failed]

Manual batch (Sync tab)

  1. Ensure metrics exist in Stored metrics
  2. Click Push to HubSpot (Batch)
  3. Batch job Id appears in toast; status shows below buttons
  4. When complete, refresh table — check HubSpot Status column
Manual batch filters by the Campaign Name currently entered on Sync tab (if set). Only Pending and Failed rows for that campaign are processed.

HubSpot properties updated

Mapped via Custom Metadata LinkedIn HubSpot Config → Default:

MetricDefault HubSpot property
Impressionslinkedin_impressions
Clickslinkedin_clicks
Conversionslinkedin_conversions
Campaign namelinkedin_campaign_name

Batch size

HubSpot Batch Size in API Settings controls how many records each batch chunk processes (default 50). Lower if hitting HubSpot rate limits; higher for faster runs on large datasets.

8. Daily auto-sync & scheduler

The scheduled Apex class LinkedInAdSyncScheduler (job name: LinkedIn Ad Sync Daily) runs automatically when configured from API Settings. 

flowchart TD
    T[Daily cron trigger] --> C{Auto Sync Enabled?}
    C -->|No| X[Exit]
    C -->|Yes| D[LinkedIn token OK?]
    D -->|No| X
    D -->|Yes| E[Build date range today minus lookback]
    E --> F[Resolve campaign list]
    F --> G[For each campaign: LinkedIn API fetch]
    G --> H[Upsert LinkedIn Ad Metric]
    H --> I[Start HubSpot batch all Pending/Failed]

Configure from UI (recommended)

  1. API Settings → enable Auto Sync Enabled
  2. Set Auto Sync Lookback Days (e.g. 30)
  3. Set Daily run hour (0–23, Salesforce org timezone)
  4. Set Default Campaign Name and Default LinkedIn Campaign Id
  5. Click Save Settings
  6. Click Schedule Daily Job

The schedule panel shows:

  • Job: Active / Not scheduled
  • Next fire time
  • Campaigns — list used by the job
Auto Sync Enabled must be ON or the scheduler exits immediately even if cron is active. Stop Daily Job aborts the cron and disables Auto Sync.

Campaign sources for scheduler

The job fetches metrics for:

  1. All active records in Custom Metadata LinkedIn Scheduled Campaign
  2. Plus Default Campaign Name / Id from Integration Settings (if not duplicate)

Date range used by scheduler

SettingEffect
Auto Sync Lookback DaysStart = today − N days; End = today
Report Start/End on Sync tabUsed for manual fetch only, not scheduler

Alternative: Setup → Schedule Apex

Admins can also schedule manually:

Setup → Apex Classes → LinkedInAdSyncScheduler → Schedule Apex

Daily at 6:00 AM cron: 0 0 6 * * ?

Prefer the UI buttons — they manage the job name and settings consistently.

12. FAQ

Do we use Campaign Group id?
No. Use campaign/ad set id from campaignIds=[704412604].

Does scheduler use Sync tab dates?
No. It uses lookback days ending today.

Will HubSpot create new companies?
No. Only existing companies with exact name match are updated.

Can I sync one campaign manually?
Yes — set Campaign Name on Sync tab, then Push to HubSpot.

What happens to Failed rows?
They are included in the next batch run (manual or scheduled).

13. Full setup checklist

One-time admin

  • Create HubSpot company properties (impressions, clicks, conversions, campaign)
  • Verify LinkedIn HubSpot Config CMDT mapping
  • Add LinkedIn Scheduled Campaign CMDT records (if multiple campaigns)
  • Configure Remote Site / Named Credentials (if used)

Per-environment setup

  • API Settings: LinkedIn token + URN + HubSpot token → Save → Test both
  • Sync: Campaign Name + Id → Save Sync Defaults
  • Test Fetch or CSV import
  • Push to HubSpot (Batch) — verify Synced status
  • Enable Auto Sync, set lookback + hour → Schedule Daily Job
  • Confirm Next fire time in schedule panel
